# Play listing artwork — October 14, 2026

These five assets were rendered from actual Android 61 captures and visually
checked. The screenshots show results, coaching feedback, progress/badges and
Games, in that order. They are saved in the Play main-listing draft, alongside the
new feature graphic. The current live listing has not been republished.

The renderer is `scripts/generate-play-store-refresh.mjs`. Run it from the website
root with a private capture directory and a separate output directory. Private
capture provenance is retained outside Git. It wraps actual screens rather than
inventing product interfaces. Past Results contains scorecards and feedback, not
old playable videos; the feedback caption explicitly refers to current-result
listening. Example scores and shot-speed estimates are not accuracy guarantees.

This asset commit does not redeploy buddyllc.app. The approved published website
source remains 45fae62. App public release, provider/youth compliance, declarations
and reviewer access remain separate gates in the application release handoff.
